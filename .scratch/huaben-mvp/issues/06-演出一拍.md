# 06: 演出一拍

**What to build:** 建立一局（选演员表、世界书、预设），点开演得到第一拍正文，以小说排版流式出现；写一句导演指令演下一拍。素材在开局时冻结进对局，之后改素材不影响本局。含设置页（API 地址、密钥、模型、预算、字数区间）、视角名映射、原始输出视图与 token 用量。

**Blocked by:** 05, 12

**Status:** done

- [ ] 填好设置后能真实调用模型，正文流式逐段出现
- [ ] 正文以小说排版呈现，不是聊天气泡
- [ ] 能连着演两拍，第二拍接得上第一拍的最后一句
- [ ] 开局后修改角色卡，重新打开本局仍使用旧版本
- [ ] 设置页可改 API 地址与模型名，无需重启
- [ ] 能查看这一拍实际发出的完整 prompt 与模型原始输出
- [ ] 能查看这一拍消耗的 token
- [ ] 模型调用失败时不推进消息树，重试沿用完全相同的内容
- [ ] 删除素材时提示被哪些对局引用；素材删除后旧对局仍能打开
- [ ] 导演不在场：`{{user}}` 按配置的视角名替换，不出现"你"
- [ ] 演出接缝有自动化测试，用假模型断言 prompt 与正文解析
