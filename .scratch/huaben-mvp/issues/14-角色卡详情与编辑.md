# 14: 角色卡详情与编辑

**What to build:** 点开素材库里的任意角色卡，看到它的全部内容——名字、描述、登场引子、性格、场景、示例对话、标签、备选开场白——并就地修改保存，改完列表立刻反映。

结构化表单覆盖常用字段；另有一个 JSON 视图可编辑完整内容，包括酒馆带进来、本项目暂时不用的那些字段（`extensions`、`nickname` 之类），不能因为界面没有输入框就把它们丢掉。
