# 02: 导入角色卡与保真度报告

**What to build:** 把酒馆导出的 PNG 卡或 JSON 卡拖进素材库，卡的字段被填进表单、头像显示出来；导入完成时给出一份保真度报告，说明哪些字段读到、哪些被忽略、哪些被有损转换。V2 与 V3 都能读；`ccv3` 与 `chara` 并存时以 `ccv3` 为准。

**Blocked by:** 01

**Status:** done

- [ ] 拖入真实 PNG 卡后，名字、描述、登场引子与头像都出现在表单里
- [ ] JSON 格式的 V2 卡与 V3 卡各导入一张，字段都正确落位
- [ ] 一张同时带 `ccv3` 与 `chara` 的 PNG，以 `ccv3` 的内容为准
- [ ] 导入完成的保真度报告对每张卡都非空，且分类到读到、忽略、有损
- [ ] 重复导入同一文件时询问覆盖还是另存，不静默覆盖
- [ ] 界面上能看到这张卡原本的规范版本
- [ ] 损坏或非卡的 PNG 给出具体原因，而不是"导入失败"四个字
- [ ] 导入接缝有自动化测试，用真实文件作为 fixture
