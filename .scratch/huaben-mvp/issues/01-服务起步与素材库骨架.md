# 01: 服务起步与素材库骨架

**What to build:** 一条从"打开终端"到"看见自己的第一张角色卡"的完整路径。`pnpm dev` 起本地服务，浏览器打开就是素材库；能新建一张角色卡（名字、描述、登场引子），保存后出现在列表里，刷新与重启都不丢。此时没有导入、没有世界书、没有对局。

**Blocked by:** None (can start immediately)

**Status:** done

- [ ] 一条命令起服务，浏览器打开即是素材库，无需额外配置
- [ ] 能新建一张角色卡并填写名字、描述、登场引子
- [ ] 保存后立即出现在素材列表里
- [ ] 关闭服务再启动，那张卡仍在
- [ ] 素材库为空时显示明确的"新建或导入"引导，而不是空白页
- [ ] 数据只落本地文件，无任何云端依赖
- [ ] 删除素材后列表正确更新
